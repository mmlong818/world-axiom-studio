# 万象铸界 · 世界观生成工作台

一个可在本机运行的网页版世界之书生成工具。它接受一句简要说明或一本书，既可以创造新世界，也可以依据材料还原已有世界。工作流是“提供依据 → 选择世界模型 → 构建世界之书 → 一致性审计 → 发布”，最终输出可查阅的图文 Wiki、三分钟世界概览与结构化 JSON。

世界之书不是设定项清单、风物考据专著，也不是故事开场。正文由六个相互引用的部分组成：一眼看懂这个世界、世界如何运转、地方与彼此关系、历史为何形成今天、人们怎样生活、重要名称与查阅条目。它先帮助读者建立整体认识，再逐步补充细节；最后只保留 8–12 个理解世界不可缺少的条目。基础规律通过可观察的事实和生活后果呈现，不适用或没有依据的内容保持空白。游戏、小说和视觉设计只作为下游应用层，不能反过来制造世界事实。

文本生成只使用一套统一的“世界讲解者与设定编辑”系统规则。候选、正文、审阅、修补和简版阶段只传递当前任务与用户数据，不再加载旧版模式提示、内部样例提示或题材专用提示。

世界列表是独立的上级页面。只有创建或打开一个世界后，才会进入“提供依据 → 选择模型 → 构建世界之书 → 一致性审计 → 发布”的五步工作台。

列表只保存用户创建的世界。进行中的世界可以归档；归档后可以恢复，也可以经过二次确认永久删除。为了避免误删，未归档世界不能直接删除。

## 直接运行

需要 Node.js 20 或更新版本。

```powershell
npm install
npm start
```

浏览器打开：`http://127.0.0.1:4177`

启动器会在 Node.js 24 或更高版本中自动接管 `HTTP_PROXY` / `HTTPS_PROXY`，避免网页服务可以启动、但 OpenAI 等模型端点一直连接超时。服务商、模型 ID 和端点会保存在浏览器中；API Key 仍然只保留在当前页面内存，刷新后需要重新填写。

产品只使用真实模型生成。首次使用时在“模型与接口”中选择服务商、确认模型 ID 和端点，并填写当前服务商的 API Key。创造模式会提供三份具体、可读的世界介绍方向；还原模式会让三张候选共享同一事实底座，只改变介绍重点。

## 真实模型模式

在页面左下角打开“模型与接口”，切到“真实模型”，选择服务商并填写：

- 模型 ID
- API 端点
- API Key

内置 OpenAI、Anthropic、Gemini、DeepSeek、智谱、Kimi、MiniMax、通义千问、豆包、xAI 与自定义 OpenAI 兼容端点。所有端点和模型 ID 都可以编辑；也可连接本机模型服务。

API Key 只保留在当前页面内存中：不会写入浏览器存储、项目文件或服务日志，关闭页面即消失。

## 支持的书籍格式

- PDF（需包含可选中文字）
- EPUB
- DOCX
- TXT、Markdown、HTML

扫描版 PDF 需要先做 OCR。单文件上限 25 MB。程序只向模型发送结构分析所需的采样：开篇与目录附近、均匀分布在全书的八个片段、结尾及规则说明性段落，不会把原书写入本地数据库。

对在版作品，生成提示会强制只提取抽象结构，不续写、不做同人、不复制专有设定或换名照搬。商业发布前仍应自行核对版权与开放许可条款。

## 生成与导出

1. 输入世界命题、已知事实或上传书籍，并选择创造或还原。
2. 可选调整关键约束、异常规律、文明时相、规则可变性与世界覆盖范围，也可交给系统判断。
3. 系统先建立一份材料事实底稿，再提供 3 个世界概述供选择。还原模式的底稿保存书籍中明确的规律、地方、人群、组织、历史、生活和重要事物，后续正文都沿用这份底稿；创造模式只把用户明确输入记为硬约束。
4. 系统依次写出整体概览、运转方式、地方关系、历史来由、日常生活和重要名称。条目只承担查阅作用，不重复正文已经说清的内容。
5. 审计器检查自然规律、资源循环、空间尺度、历史演化、制度来源、普通人生计、知识状态、条目交叉引用与来源分层；还原模式另外检查事实、推断、争议、新增设计与未知是否越界。
6. 下载：
   - 独立世界之书 Wiki HTML（包含六部分目录、来源层与 3 张离线结构图）
   - 世界概览 Markdown
   - 世界模型与成书结构 JSON

完整世界按四批生成，每完成一批就保存一次。如果模型超时或接口临时失败，页面会显示“从中断处继续”，不会重新生成已经完成的部分。

每批正文保存前还会经过本地完整性检查：必须包含对应的明确章节标题，并达到最低有效内容量。模型返回被截断、只有提纲或缺少章节时，该批不会写入世界档案，用户可以直接从中断处重试。创造和还原模式都必须先识别出有效的输入约束；输入没有进入结果时不会继续生成。

图片模型是可选项。未配置图片模型时，Wiki 会使用与世界种子联动的编辑式结构图；配置后可生成 3 张 AI 配图替换它们。封面图位于世界开头，地方关系图插入“地方与彼此关系”，世界关系图插入“人们怎样生活”，不是把所有图片集中堆在正文前面。图片接口若返回临时网址，服务会尝试下载并转成内嵌数据；下载失败时，独立 Wiki 自动改用本地结构图，保证离线打开不会出现空白图片。

## 验证

```powershell
npm run check
npm test
```

`check` 检查全部 JavaScript 语法；`test` 覆盖书籍采样、文本提取、提示词边界、提供商配置和世界归档删除边界。真实模型调用需要用户自己的接口与额度，因此自动测试不会产生外部费用。

## 项目结构

- `server.mjs`：本地网页服务与 API 边界。
- `lib/extractors.mjs`：PDF、EPUB、DOCX 与纯文本解析、书籍采样。
- `lib/providers.mjs`：多模型协议适配与图片接口。
- `lib/prompts.mjs`：世界模型、分层构建、审计、修补和世界概览提示。
- `public/`：无构建步骤的网页工作台与导出器。
